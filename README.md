# Farangiz.dev — Portfolio

## Ishga tushirish
1. ZIP faylni kompyuterga chiqarib oling.
2. `farangiz-portfolio` papkasini oching.
3. `index.html` faylini brauzerda oching.

Loyiha oddiy HTML, CSS va JavaScript asosida yozilgan. `npm install` yoki build qilish shart emas.

## Vercel'ga joylash
1. GitHub'da yangi repository yarating.
2. Papka ichidagi `index.html`, `style.css`, `script.js` va `README.md` fayllarini repository'ning asosiy qismiga yuklang.
3. Vercel'da **Add New → Project** ni tanlang va shu repository'ni ulang.
4. Framework Preset: **Other**.
5. Build Command va Output Directory maydonlarini bo‘sh qoldiring.
6. Deploy tugmasini bosing.

`index.html` root papkada bo‘lishi kerak. Bu statik sayt bo‘lgani uchun `package.json`, React build yoki server sozlamasi talab qilinmaydi.

## O‘zgartirish
- Matnlarni `index.html` ichidan tahrir qiling.
- Ranglar va dizayn `style.css` ichida.
- Menyu, rang rejimi va animatsiyalar `script.js` ichida.
- GitHub loyihalarining alohida havolalari tayyor bo‘lsa, `index.html` ichidagi loyiha kartalaridagi GitHub havolalarini almashtiring.
- Profil rasmi qo‘shmoqchi bo‘lsangiz, keyingi versiyada hero qismidagi grafik o‘rniga o‘z rasmingizni qo‘yish mumkin.

## Eslatma
Google Fonts internet mavjud bo‘lganda yuklanadi; internet bo‘lmasa tizim shriftlari ishlaydi. Saytning asosiy funksiyalari tashqi kutubxonalarga bog‘liq emas.
